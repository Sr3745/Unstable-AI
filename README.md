🎭 Emotionally Unstable AI 😡😭🥰

Built for the Useless Projects Hackathon

Meet the Emotionally Unstable AI: a Google Gemini-powered chatbot that is finally allowed to have a bad day. In a tech landscape saturated with perfectly polite and predictable digital assistants, this interactive web application delivers the authentic human experience of emotional volatility. Built with Node.js and hosted on Vercel, the AI dynamically swings from furious anger to clingy affection based entirely on your conversation's tone—ensuring your interactions are never productive, but always unpredictable and hilarious.

✨ Features

Volatile Personalities: The chatbot unpredictably swaps between Angry, Sad, Loving, and Happy states depending on what you say.

Dynamic User Interface: The application's background colors and UI elements shift in real-time to match the AI's current emotional breakdown.

Powered by Gemini: Leverages the Google Gemini API to generate context-aware, highly emotive, and often unhinged conversational responses.

🛠️ Tech Stack

Frontend: HTML, CSS, Vanilla JavaScript

Backend: Node.js, Express

AI Integration: Google Gemini API

Deployment: Vercel

🚀 Local Setup & Installation

If you want to run this emotionally unstable bot locally, follow these steps:

Clone the repository:

git clone https://github.com/yourusername/emotionally-unstable-ai.git
cd emotionally-unstable-ai


Install dependencies:

npm install


Set up your Environment Variables:
Create a .env file in the root directory and add your Google Gemini API key:

GEMINI_API_KEY=your_api_key_here


Start the server:

npm start


Open your browser and navigate to http://localhost:3000 to start ruining the AI's day.
